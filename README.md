Jogo de Adivinhação (1 a 50)
Este é um simples jogo de adivinhação criado em Python, ideal para praticar estruturas de repetição, condicionais e geração de números aleatórios.

Objetivo
O jogador tem até 15 tentativas para adivinhar um número aleatório entre 1 e 50. A cada jogada, o programa informa se o número digitado foi maior, menor ou igual ao número sorteado.

Funcionalidades
- Geração de números aleatórios com `randint`
- Comparação entre valores do jogador e do computador
- Contador de acertos
- Validação do número digitado

Como executar
Copie o código para um arquivo com extensão, ou baixe o arquivo
Execute o script no terminal com o comando: `jogo-adivinhação.py`
Siga as instruções no terminal e tente acertar o número!

Aprendizados
Este projeto ajuda a fixar conceitos como:
- Laços `for`
- Condicionais `if`, `elif`, `else`
- Uso do módulo `random`
- Interação com o usuário via `input()`
